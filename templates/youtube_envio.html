1️⃣ Credencial do Google

Como criar (uma vez só, ~5 min)
  1. Em console.cloud.google.com, crie um projeto.
  2. APIs e serviços › Biblioteca → ative a YouTube Data API v3.
  3. Tela de consentimento OAuth → tipo Externo; em Usuários de teste ponha o seu Gmail. Depois clique em Publicar app (em produção) — no modo "Teste" o Google desconecta a conta a cada 7 dias.
  4. Credenciais › Criar › ID do cliente OAuth → tipo Aplicativo da Web → em URIs de redirecionamento autorizados cole:
    {{ redirect_uri }}
    (tem que ser exatamente esse endereço — se você abre o site por outro, ex. localhost, use o daquele)
  5. Baixe o JSON da credencial (⬇) e envie aqui embaixo.
⚠ Regra do Google: enquanto o projeto não passar pela auditoria da API do YouTube, todo vídeo enviado pela API fica privado (dá pra mudar pra público no Studio à mão). A cota grátis permite até 100 envios por dia por projeto (fora o limite do próprio canal).
